# Widgets used in the README

| Widget | What it communicates |
|---|---|
| GitCity | 3D contribution skyline; click through to the driveable interactive city |
| GitHub Readme Stats | Repository, commit, star and PR/issue metrics |
| Streak Stats | Current and longest contribution streak |
| Top Languages | Language share across public repositories |
| Activity Graph | Contribution activity over time |
| Contribution FX | Animated transformation of the contribution calendar |
| Profile Trophy | GitHub profile achievement cards |
| Profile Views / Followers | Profile traffic counter and follower count |
| Skill Icons | Compact technology stack |

The stats and animation services are third-party hosted services. Their availability, themes, rate limits and API behaviour may change.
